## What I build

- **Agentic systems** — orchestration, tools, memory, evaluation, and human
  checkpoints for workflows that need more than a prompt.
- **Intelligent products** — machine learning and data capabilities translated
  into interfaces, decisions, and measurable outcomes.
- **Reliable automation** — integrations and execution loops with explicit
  constraints, observability, and verification built in.

At **LCGBR**, I connect this work to MarTech, customer data, and real product
delivery.

## Engineering loop

```text
 DISCOVER  ──▶  DESIGN  ──▶  BUILD  ──▶  VERIFY
    ▲                                      │
    └──────────── learn and refine ────────┘
```

I treat verification as part of the architecture. Requirements become explicit
constraints, execution stays observable, and feedback improves the next
decision.

## Working principles

- Make constraints and outcomes explicit before scaling execution.
- Give AI systems the context, tools, memory, and feedback loops they need.
- Keep decisions traceable from source data to user-facing behavior.
- Build the verification path alongside the implementation path.
